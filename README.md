# LEMBEM LAB — Research Landing Page

A static public-interest research website based on the HTML/Tailwind visual language of [AgriSense](https://github.com/yanghoxom/agrisense-ai).

## Files

- `index.html` — research landing page: mission, three pillars, projects, governance, publications, support, contact
- `governance.html` — transparency and institutional details
- `privacy.html` — privacy notice
- `terms.html` — website use and licensing
- `favicon.svg` — separate LEMBEM favicon
- `.nojekyll` — GitHub Pages compatibility

## Publishing

This site is plain HTML and uses Tailwind via CDN. No build step is required. Enable GitHub Pages for the `main` branch, root directory, or point a static host to this repository. A custom domain requires separate DNS and hosting configuration.

## Data that must be verified before describing as official

- Official registration, statutory tax identifier, organizational headquarters
- Legally appointed board members and registered legal representative
- Whether `contact@lembem.com` is active and under your control
- Status, provenance, release and specific licence of VietBioNet, EcoModel-VN, or datasets
- Donation-acceptance eligibility, institutional bank account
- A legal organizational charter and actual non-distribution restrictions

The hero describes the non-profit research initiative without asserting confirmed registration; statutory status is not independently verified by these repositories.

The AgriSense source site describes an early-stage concept. This version does not label it a completed community deployment.
